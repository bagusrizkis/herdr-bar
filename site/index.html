Herdr Bar

Live status of your Herdr coding agents in the macOS menu bar. Work on something else and glance up.

Install

brew trust bagusrizkis/tap
brew install --cask bagusrizkis/tap/herdr-bar
curl -fsSL https://raw.githubusercontent.com/bagusrizkis/herdr-bar/main/install.sh | sh

Requires macOS 26 and Herdr 0.9 or newer. Releases are signed with a Developer ID certificate and notarized by Apple. Prefer a manual install? Get the DMG from the latest release.

What you get

  • Popover with every agent grouped by space, or as a priority queue: needs input first, then working, done, idle.
  • Peek at an agent's last message without switching to the terminal.
  • Notifications when an agent needs your input or finishes.
  • Multi-session: default and named Herdr sessions, discovered automatically.
  • Push, not polling: one streaming subscription to Herdr's socket API.

Herdr plugin

Optional: install Herdr Bar as a Herdr plugin so it launches with the Herdr server and receives agent events directly.

herdr plugin install bagusrizkis/herdr-bar
